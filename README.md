## 🚀 Featured Project

### 🛍️ Product Review Analysis & Smart Recommendation System

An **AI-powered Flask web application** that predicts customer review sentiment using Machine Learning and recommends relevant products using Natural Language Processing techniques.

**✨ Key Features**

| Feature | Description |
|---|---|
| 🎯 Sentiment Analysis | Classifies reviews using a trained ML model |
| 📊 Prediction Categories | Positive / Neutral / Negative sentiment output |
| 🛒 Product Recommendation | Suggests similar products based on review content |
| 🌐 Flask Web Application | Full-stack web app with a clean UI |
| 🧮 SVM Model | Core classification algorithm for sentiment prediction |
| 🔤 TF-IDF | Text vectorization for feature extraction |
| 📐 Cosine Similarity | Measures product/review similarity for recommendations |
| 📱 Responsive UI | Works seamlessly across devices |
| 🤖 Machine Learning | End-to-end ML pipeline |
| 🗣️ NLP | Natural Language Processing for text understanding |
